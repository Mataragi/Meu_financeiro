# Prompt Library

Esta pasta contém todos os templates oficiais utilizados para interação com o Codex.

Cada template possui um propósito específico.

## Arquivos

- BASE_TEMPLATE.md
- FEATURE.md
- REFACTOR.md
- BUGFIX.md
- TESTS.md
- AUDIT.md
- DOCUMENTATION.md

## Utilização

Todo novo prompt deverá utilizar um dos templates existentes.

Evite criar prompts do zero.

Caso um novo padrão seja necessário, primeiro atualize a biblioteca.
